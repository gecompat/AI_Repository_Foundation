# Project Context

Status: AUTHORITATIVE

## Purpose

Maintain a reusable, vendor-neutral repository foundation that makes AI-assisted projects self-describing, governable, and safely continuable without prior conversations or proprietary prompts.

## Scope

- cross-project governance and continuation contracts;
- bootstrap and deterministic validation;
- thin tool adapters;
- templates suitable for software, research, data, and documentation repositories.

## Non-goals

- project-specific domain logic, architecture, build commands, or backlog;
- fixed programming languages or frameworks;
- concrete AI model names, prices, providers, accounts, hosts, or environments;
- chat histories, personal notes, scratchpads, real data, secrets, or internal artifacts;
- blanket permission for autonomous implementation.

## Project properties

- repository visibility: public
- documentation language: English
- technical identifiers: canonical spelling
- license: MIT for this Foundation repository
- target-project license: independent project decision
- default Git workflow: branch_and_pr
- merge strategy: project-selectable
- decision authority: material, privacy, security, destructive, and irreversible decisions require explicit authorization unless a target project defines a stricter rule.
