# Project Context

Status: AUTHORITATIVE

## Purpose

Maintain a reusable, vendor-neutral repository foundation that makes AI-assisted and AI-driven technical and knowledge projects self-describing, governable, and safely continuable without prior conversations or proprietary prompts.

## Scope

- cross-project governance and continuation contracts;
- an explicit manifest of transferable rules;
- deterministic planning/installation and validation tools;
- direct AI-to-repository transfer using the same manifest;
- thin tool adapters;
- rules suitable for software, research, data, architecture, documentation, automation, education, and mixed repositories.

## Non-goals

- project-specific domain logic, architecture, build commands, README, license, backlog, status, or handover;
- fixed programming languages or frameworks;
- concrete AI model names, prices, providers, accounts, hosts, or environments;
- chat histories, personal notes, scratchpads, real private data, secrets, or internal artifacts;
- blanket permission for unbounded autonomous implementation;
- copying Foundation-project state into target repositories.

## Project properties

- repository visibility: public
- documentation language: English
- technical identifiers: canonical spelling
- license: MIT for this Foundation repository
- target-project license: independent project decision; installation must not replace it
- default Git workflow: branch_and_pr
- merge strategy: project-selectable
- decision authority: ordinary task-authorized work proceeds autonomously; durable material decisions require an appropriate decision record when relevant; security/privacy/high-impact effects require clear task or project authority; destructive/irreversible effects require exact target authority.
